# チーム共有セットアップ手順（Google Sheets連携）

所要時間の目安: 5〜10分。エンジニア不要、Googleアカウントがあれば誰でもできます。
**この作業は、チームの中で1人が1回だけ行えば大丈夫です。**

## 1. Googleスプレッドシートを新規作成する

1. Google Driveで新しいスプレッドシートを作成する
2. 名前を「SNS Ops Command Center - データ」などわかりやすい名前に変更する
3. **これ以降、このシートのA1・B1セルは手動で編集しないでください**（アプリが自動で使う場所です）

## 2. Apps Scriptを設定する

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. デフォルトで表示される`myFunction`等のコードを全て削除する
3. 同封の`Code.gs`の中身を全てコピーして貼り付ける
4. 画面上部の「保存」（フロッピーディスクのアイコン）をクリックする
5. プロジェクト名を聞かれたら「SNS Ops Sync」などの名前をつける

## 3. Webアプリとしてデプロイする

1. 画面右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコンから種類の選択で「ウェブアプリ」を選ぶ
3. 以下のように設定する
   - **説明**: 任意（例: 初回デプロイ）
   - **次のユーザーとして実行**: 自分（あなたのアカウント）
   - **アクセスできるユーザー**: **全員**（重要：「全員」を選択してください。「Google アカウントを持つ全員」ではなく「全員」です）
4. 「デプロイ」をクリック
5. 初回は権限の承認画面が出るので、自分のGoogleアカウントで承認する（「このアプリは Google で確認されていません」という警告が出ますが、自分で作ったスクリプトなので「詳細」→「（プロジェクト名）に移動」で進めて問題ありません）
6. デプロイが完了すると、**ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`という形式）が表示されるので、これをコピーする

## 4. アプリ側にURLを設定する

1. SNS Ops Command Centerを開く
2. ヘッダーの「チーム共有設定」ボタンをクリック
3. コピーしたURLを貼り付けて「接続する」をクリック
4. ヘッダーのバッジが「同期済み」になれば成功です

**この手順4だけは、チームメンバー全員がそれぞれのブラウザで行う必要があります**（同じURLを、各自のブラウザで設定してください）。

## 5. 動作確認

1. 自分のブラウザで何か投稿を編集して保存する
2. 数秒待ってから、Googleスプレッドシートを開き、A1セルに長いJSON文字列が入っていることを確認する
3. 別のブラウザ（または別のPC）で同じURLを設定し、編集した内容が数秒以内に反映されることを確認する

## トラブルシューティング

### バッジが「オフライン」のまま変わらない
- URLの末尾が`/exec`になっているか確認してください（`/dev`ではありません）
- デプロイ時のアクセス設定が「全員」になっているか確認してください（Apps Scriptの「デプロイを管理」から確認・修正できます）
- ブラウザで直接そのURLを開いてみて、`{"state":{...},"updatedAt":"..."}`のようなJSONが表示されるか確認してください。エラー画面が出る場合はデプロイ設定を見直してください

### コードを修正したのに反映されない
- Apps Scriptはコードを保存しただけでは反映されません。「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン→ バージョンを「新バージョン」にして「デプロイ」し直してください（URLは変わりません）

### 「競合を解決しました」という表示が出た
- ほぼ同じタイミングで別の人が保存した場合に出るメッセージです。異常ではありません。表示された最新の内容をもとに、直前の変更を再度入力してください

## 制限事項（正直な注意点）

- 数秒間隔のポーリング方式のため、真の意味での瞬時反映ではありません（体感としてはほぼリアルタイムに近いです）
- 同時に同じ項目を編集した場合、後から保存した方が優先されます（先に保存した人の変更は失われる可能性があります。競合時は上記の通り警告が出ます）
- Apps Scriptの無料枠には1日あたりの実行回数上限があります（個人アカウントで1日あたり数万回程度）。数人〜十数人規模のチームであれば十分な余裕があります
