レッスンの内容を「型」に流し込んで、コース全体で一貫したスライドを生成するためのページ型カタログ。コースの流れ（コース全体 → 導入 → 本編 → 定着・締め）の4フェーズで、28の型を用意した。本編（C）は IT・ビジネス・語学 の教材に合わせ、画像解説・UI操作・コード・例文対訳・会話などを網羅。さらに本編は「思考の流れ＝フレームワーク」12種（C+セクション）で、型を並べる順番ごと組み立てられる。中身の可視化は別紙パターンライブラリ（グラフ・図解）を各型のコンテンツゾーンに差し込む。

流 レッスンのリズム4 PHASES

型は「並べる順番」で意味を持つ。1レッスンは 導入 → 本編 → 定着・締め を基本の骨格にし、コース全体は最初に コース全体 の型で枠を示す。本編（C）の型は内容に応じて選び・増減する。

PHASE A
コース全体
コースの入口と地図。表紙・カリキュラム・チャプター扉。
PHASE B
導入（Open）
この回への引き込み。表紙・目標・動機づけ・前提。
PHASE C
本編（Teach）
中身を教える。概念・手順・例・比較・データ・図解…。
PHASE D
定着・締め（Close）
手を動かし、確認し、次へ。演習・チェック・まとめ・CTA。

content.txt は各型とも 【セクションラベル】【タイトル】【…】 の同じ記法で書き、slides-gen が型を判定して割り当てる。各カードの「スロット」がその型の可変項目。

C+ 本編フレームワークTEACH FLOWS · 12

本編（C）は「思考の流れ」そのもの。上の15型を単体で並べるだけでなく、思考フローの順に組むと1本の本編になる。フローを型化したもの＝フレームワークで、頭の整理だけでなくスライドの見せ方そのものになる。青チップ＝主となる型／グレー＝補助。作り手はコース内容に応じて選び・増減する。

例：課題解決フレーム（添付資料の型）　目的：課題の全体像から本質原因を特定し、解決策とその効果を納得感をもって伝える。「思考の流れ＝スライド構成」の代表例。

思考の流れ（フレームワーク）
1現状把握▸ 2課題の分解▸ 3原因の深掘り▸ 4解決方針の設計▸ 5Before / After▸ 6実行
スライド構成（既存の型に落とす）
レッスン表紙› データ／問題提起› 構造：ロジックツリー› 構造：なぜなぜ分析› 比較／解決方針› ビフォーアフター› 手順：実行ステップ› まとめ

使い方

フローを指定すると、章扉＋本編を一括生成（例 【本編:概念習得】）。content.txt に材料の見出しを入れるだけで1チャプター分が組める。フィールドの無いページは自動スキップ。

長尺化（実コース想定）：コースは Chapter 10 × 15枚規模。リスト系フィールド（details＝構成要素／examples＝事例／applications＝応用）は「項目の数だけ1枚ずつ」に展開（fan-out）し、間に小扉も入る。要素・事例を増やすほど厚くなり、1ブロックで15枚規模のチャプターになる（マーケ講座の「各要素を1枚ずつ→事例に当てはめる」パターン）。

ライブラリ紐付け：各フローは別紙パターンライブラリの可視化を直接呼ぶ。図解（フロー図・ピラミッド・Before/After・ツリー等）＝常時／グラフ（data＝ラベル=値で円・棒）・表（table＝h1,h2｜a,bで罫線表）＝フィールドがあれば挿入。アイコン/イラスト（併用）：アイコンは強調したい文章の横に置く（why_icons＝動機づけカードの見出し横に Phosphor 1色）。イラストはillust＝修了などの主役に soco-st カラー（章扉は使わない）。グラフは太リング＋凡例、表は行数で高さ調整し、文字とのバランスを取る。脱・機械配置：詳細スライドは非対称レイアウト（大きな主張＋根拠／罫線なし段組み／上結論・下詳細）をローテーションし、連続で同じ型にしない。wf型接続：wf＝W03=タイトル｜…で本編ワイヤー50型を差し込める（本文はwf既定を作り手が差し替え）。

実装状況：TF2 概念習得型＝実装済み・長尺対応・ライブラリ紐付け済み（frameworks.py）。TF1〜7＝汎用の中心、TF8〜12＝場面特化。TF1 課題解決の「なぜなぜ分析図」など一部は専用ビルダーを順次追加。
