## 1. お役立ち資料（resources.html）【後ほど対応】

- [ ] **フォームの送信先を決めて接続する**
  - 入力された「お名前・メールアドレス・お知らせ希望・どの資料か」の保存先です。
  - 候補：HubSpot、Googleフォーム、使っている CRM など。
  - コード上は `resources.html` の送信処理に `TODO` を残しています（`gen_resources.py` の script 内）。
- [ ] **各資料の PDF ファイルと URL を用意する**
  - 今の6件（SNS投稿 企画シートなど）は見本です。実際の資料に差し替えてください。
  - URL が未設定の間は、完了画面に「PDFのURLを設定」と表示されます。
- [ ] （任意）ダウンロードと同時に、同じリンクをメールでも送る
  - 実在するメールアドレスか確認できるようになります。メール配信の仕組みが必要です。

## 決定済みの方針（参考）

| 項目 | 決定内容 |
|---|---|
| 返金 | 決済後は原則不可。当社の責任で受講できないときは個別対応 |
| 受講期間 | アカウントがある限り、サービス提供中は期限なし |
| 月額費用 | コースは買い切りで月額なし。コミュニティ・ポートフォリオで将来、月額制の可能性あり |
| 動作環境 | パソコン推奨、スマホ・タブレットでも受講可。推奨ブラウザは Chrome・Safari・Firefox・Edge の最新版 |
| ポートフォリオの公開範囲 | 作品ごとに「自分だけ／会員のみ／全体に公開」。投稿直後は「自分だけ」 |
| 外部への情報送信 | Google アナリティクスのみ |
| 裁判所 | 横浜地方裁判所 |
| 特商法の責任者・所在地・電話番号 | 「請求があれば遅滞なく開示する」と記載 |
| About ページ | 作らない。フッターは「運営会社」（外部リンク）のみ |
| フッターの入口カード（相談・パンフレット・LINE） | 削除。各ページですでに案内できているため |
