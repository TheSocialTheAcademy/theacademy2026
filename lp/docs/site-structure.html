The Academy サイト構成案

現行サイト（theacademyjapan.org トップ）と新LP案を突き合わせ、ヘッダー・LP・各ページへの振り分けとLPの流れを組み直しました。v2でプロトタイプへのフィードバックを反映し、v3で下層ページ（コースを探す・学び方・ポートフォリオ・学びのヒント・はじめての方へ）の項目とページ間のつながりを決めました（6章）。

結論

  1. LPは「約束 → 入口 → 3つの仕組み（学ぶ・残す・飛び込む） → 中身 → 不安の解消 → 行動 → 受け皿」の順。 02 WHY を目次にして、03コース・04ポートフォリオ・05コミュニティーを同じ順で続け、LPの3つのゴールすべてに導線を通します。
  2. 行動の入口を重さ別に3段にします。 重い順に「無料相談」「資料請求（パンフレット）」「LINE登録」。迷っている人（ターゲットB）でも、どこかの段で接点を残せます。
  3. 02は「強み（学ぶ・残す・飛び込む）」を採用。 HOW TO LEARN（3ステップ）は「学び方・受講成果」ページへ。
  4. コミュニティーは、まずGoogleフォームで人を集めて方向性を固める段階。 LPの05セクションと申し込みボタンだけを置き、専用ページとヘッダーのリンクは作りません。

3. 【相談】への回答

02　強みを出すか、HOW TO LEARN（3ステップ）を出すか

LPは強み（学ぶ・残す・飛び込む）。3ステップは「学び方・受講成果」ページへ。

  • LPの役割は「なぜThe Academyか」を示すこと。3つの仕組みはLPの3つのゴールと直接つながりますが、3ステップはコースの中の話で、ゴールの一部しか説明できません。
  • 「INPUT→PRACTICE→OUTPUT」は「続けられるか」を確かめたいB層に効くので、「学び方・受講成果」ページの冒頭に置きます。

05　相談だけでなく、パンフレットも入れたい

入れます。LPの07で、相談とパンフレットを横に並べます。

  • 相談は心理的に重い行動です。B層の多くは「まず資料で比べたい」段階にいるので、パンフレットがその受け皿になります。
  • 配置：LPの07、ヘッダーの「資料請求」ボタン、「はじめての方へ」、フッター。
  • 入力フォームは送信後すぐにダウンロードできる現行の仕組みを活かします。

08　受講までの流れを「はじめての方へ」に入れるべきか

両方に入れます。LPは短縮版（06）、「はじめての方へ」は横スライドの詳細版。

  • 流れは、申し込み直前の不安（何をすればいいか、相談は必須か）を消すための情報です。「はじめての方へ」だけに置くと、LPから申し込む人の目に入りません。
  • 現行は「①無料相談会」が最初で必須に見えるため、「①コースを選ぶ（迷ったら相談）」から始め、最後に「残す・飛び込む」を加えます。

09　LINE登録の説明を「はじめての方へ」に入れるべきか

「はじめての方へ」には横スライドの詳細を。LPにも2か所置きます。

  • LINEの役割は3つ（潜在層の受け皿、購入の後押しになる500円クーポン、ニュースレター）。どれも「すぐには申し込まない人」が相手なので、そういう人が離れる場所に置きます。
  • 配置：LPの03（コース横の小バナー）と09（最後の帯）、ブログ記事の末尾、コース詳細の価格の近く、フッター。

主張：資格やスコアでは見えない「過程」を1ページにまとめ、次の仕事やチャンスにつなげる。「主張 → 比較（測られているもの VS 見えていないもの） → 根拠（機能） → 疑問への回答 → 例 → はじめかた → 第一歩」の順。登録は無料・匿名で始められる。一覧・投稿は会員限定のため、ページ上では架空のサンプルで見せる。

  1. 見出し「積み重ねた努力を、見える形に。」＋無料で登録する／ポートフォリオの例を見る（匿名で始められます）
  2. WHY：測られているもの（資格・スコア・AI判定）VS 見えていないもの（過程・工夫・強み）→ だから公開ポートフォリオで伝える＋こんな方に（キャリアを変えたい／独学で一度立ち止まった）
  3. 伝えられること：01 学びを、そのまま実績に（実績＝背景・課題→担当範囲→制作プロセス→成果、資格・認定、学びの歩み）／02 数字だけでは見えない、あなたらしさ（ビジョン・人物像診断・強み・働き方・書籍・サービス）
  4. ひとりじゃない：ロールモデル（関連ユーザー）・フォロー・学びのフィード
  5. 公開ポートフォリオの例（架空サンプル1件：プロフィール・ビジョン・実績ストーリー・学びの歩み）※一覧は無料登録後
  6. はじめかた3ステップ（登録する／育てる／PRする・つながる）→ よくある質問（匿名／費用＝無料／他の人を見られる？／受講前でも作れる？／企業は見られる？）一部要確認
  7. 行動3択：例を見る／作る（無料登録）／コースを探す

7. 公開前に直したい点

現行サイトと新LP案を突き合わせて見つかった食い違いです。数字と表記は、信頼に直結するため優先度を高くしています。

① 数字

評価「3.0」のコースが9件あり、平均満足度「4.2」と食い違って見えます。

レビューがない状態の初期値の可能性があります。評価がないコースは星を出さず、LPの満足度は「何の平均か（調査・期間・回答数）」を確認してください。

② 数字

選ばれる理由の「5-15万円」が、実際のコース価格（2,980〜13,800円）と合いません。

TOEICプログラムの価格帯であれば、その旨を明記するか、表現を見直してください。

③ 表記

フッターにWixの初期SNSリンク（Wix公式のInstagram・Facebookなど）が残っています。また、プロジェクトマネジメントコースのURLが「/products/test」のままです。

新サイト公開時に必ず外してください。

④ 価格

LP 03の3コース（SNSマーケティング実践・生成AI 業務改善・TOEIC L&R 700点突破）の価格が未定です。

新LPのコース名・期間が現行のコースと一致しないため、新しいコースとして作るのか、既存コースの名前を変えるのかを決め、コース詳細とそろえてください。

⑤ 表現

「TOEIC L&R 700点突破」は、結果の約束に読めます。

ブランドガイドラインの「根拠のない約束をしない」に合わせ、「700点を目指す」などの言い方か、実績の注記を添えることを推奨します。

⑥ 表記

週あたりの学習時間の表記がばらついています（ヒーロー「週2h〜」／コース「週2〜3時間」「週2時間」／現行「2-3時間」）。

ヒーローは「週2h〜」で確定。コースごとの表記は「週2〜3時間」の形にそろえると読みやすくなります。

⑦ 法務

オンラインでコースを販売しているのに、特定商取引法に基づく表記がフッターに見当たりません。

通信販売では表示が義務づけられています。新フッターに追加しています。

⑧ 定義

コミュニティーの参加条件（受講生限定か／誰でもか／費用）と、LINE特典の「限定コミュニティー」との関係が未整理です。

決まるまでは、LP 05のボタン下に＊の注記で「決まり次第記載」と示します。
