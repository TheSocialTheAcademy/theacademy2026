The Academy サイト構成案

現行サイト（theacademyjapan.org トップ）と新LP案を突き合わせ、ヘッダー・LP・各ページへの振り分けとLPの流れを組み直しました。【相談】の4点への回答と、公開前に直したい点もまとめています。

結論

  1. LPは「約束 → 入口 → 3つの仕組み（学ぶ・残す・飛び込む） → 証拠 → 不安の解消 → 行動 → 受け皿」の順に並べ替えます。 02 WHY を目次にして、03コース・04ポートフォリオ・05コミュニティーを同じ順で続けると、3つのゴールすべてに導線が通ります。
  2. 行動の入口を重さ別に3段にします。 重い順に「無料相談」「資料請求（パンフレット）」「LINE登録」。迷っている人（ターゲットB）でも、どこかの段で離脱せずに接点を残せます。
  3. 02は「強み（学ぶ・残す・飛び込む）」を採用します。 HOW TO LEARN（3ステップ）は「学び方・受講成果」ページへ移します。
  4. 受講までの流れ・LINEは「はじめての方へ」だけでなく、LPにも短縮版を置きます。 詳しい横スライドは「はじめての方へ」に置きます。

3. 【相談】への回答

02　強みを出すか、HOW TO LEARN（3ステップ）を出すか

LPは強み（学ぶ・残す・飛び込む）。3ステップは「学び方・受講成果」ページへ。

  • LPの役割は「なぜThe Academyか」を示すこと。3つの仕組みはLPの3つのゴールと直接つながりますが、3ステップはコースの中の話で、ゴールの一部しか説明できません。
  • 「INPUT→PRACTICE→OUTPUT」は他社も使う型で、差がつきにくい一方、「続けられるか」を確かめたいB層には効きます。そのため「学び方」ページの冒頭に置き、LPの02 POINT 01から「学び方を見る」でつなぎます。

05　相談だけでなく、パンフレットも入れたい

入れるべきです。相談と並べて「行動の入口」を重さ別に並べます。

  • 相談は心理的に重い行動です。B層の多くは「まず資料で比べたい」段階にいるので、パンフレットがないと、その人たちの受け皿がありません。
  • 配置：LPの08（相談・パンフレット・無料体験の3択）、ヘッダーの「資料請求」ボタン、ヒーローのテキストリンク、「はじめての方へ」、フッター。
  • 入力フォームはページ内（モーダル）で完結させ、送信後すぐにダウンロードできる現行の仕組みを活かします。

08　受講までの流れを「はじめての方へ」に入れるべきか

両方に入れます。LPは短縮版、「はじめての方へ」は横スライドの詳細版。

  • 流れは、申し込み直前の不安（何をすればいいか、相談は必須か）を消すための情報です。「はじめての方へ」だけに置くと、LPから申し込む人の目に入りません。
  • 流れの中身も見直しを。現行は「①無料相談会」が最初で必須に見えます。「①コースを選ぶ（迷ったら相談）」から始め、最後に「ポートフォリオ・コミュニティーへ」を加えると、LPのゴールとつながります。

09　LINE登録の説明を「はじめての方へ」に入れるべきか

「はじめての方へ」には横スライドの詳細を。ただしLINEの役割を考えると、それだけでは足りません。

  • LINEの役割は3つ（潜在層の受け皿、購入の後押しになる500円クーポン、ニュースレター）。どれも「すぐには申し込まない人」が相手なので、そういう人が離れる場所に置く必要があります。
  • 配置：LPの03（コース横の小バナー）と10（最後の帯）、ブログ記事の末尾、コース詳細の価格の近く、フッター。

7. 公開前に直したい点

現行サイトと新LP案を突き合わせて見つかった食い違いです。数字と表記は、信頼に直結するため優先度を高くしています。

① 数字

評価「3.0」のコースが9件あり、平均満足度「4.2」と食い違って見えます。

レビューがない状態の初期値の可能性があります。評価がないコースは星を出さず、LPの満足度は「何の平均か（調査・期間・回答数）」を明記してください。

② 数字

選ばれる理由の「5-15万円」が、実際のコース価格（2,980〜13,800円）と合いません。

TOEICプログラムの価格帯であれば、その旨を明記するか、表現を見直してください。

③ 表記

フッターにWixの初期SNSリンク（Wixの公式Instagram・Facebookなど）が残っています。また、プロジェクトマネジメントコースのURLが「/products/test」のままです。

新サイト公開時に必ず外してください。

④ 導線
