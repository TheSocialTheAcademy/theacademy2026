MIGRATION GUIDE · WIX STUDIO

The Academy サイトを新デザインへ移行するための実装ガイド

いまの theacademyjapan.org（Wix Studio）を、新しいデザインと構成に移行するための引き継ぎ資料です。何を引き継ぎ、何を作り直し、何を渡すかをまとめています。対象はエンジニアと Web デザイナーです。

結論 移行の進め方 今あるものの行き先 データ フォーム 素材 動きのある部品 URL・SEO・計測 法務・個人情報 デザインの値 公開前のチェック 渡すもの 確認項目の一覧

結論

1. 新しいサイトを別に作らず、今の Wix Studio サイトの中で作り替えます。
コース（商品）・注文・会員・連絡先・ブログ記事・フォームの受信履歴・検索順位は、今のサイトに結びついています。別のサイトで作ってドメインを付け替えると、これらの移し替えが必要になり、漏れや二重管理が起きやすくなります。同じサイトの中でページとデザインを作り替えれば、そのまま引き継げます。

2. 作業中の変更は公開せず、最後に一度で切り替えます。
Wix は「保存」と「公開」が分かれていて、公開するとサイト全体が一度に反映されます。新しいページを作り終えるまで公開しない運用にし、作業中に今のサイトを直す必要が出たら、その手順を先に決めておきます（移行の進め方）。

3. いまの HTML は「完成見本」です。Wix にそのまま貼りません。
見た目・文言・動きの正解として使い、Wix Studio のエディタと CMS で作り直します。

4. 移行で特に気を付けるのは3つです。今の URL を新しい URL へ転送すること、コース（商品）とコース詳細のつなぎ方、フォームの受け取りと個人情報の書き方です。

4. ページを作る新しいページを作る（公開しない）。今のページは残したまま、作り終えたら差し替える全ページ（非公開の状態）

作業中の運用を決めておく：作業期間中に今のサイトを直すと、作りかけの新しいページも一緒に公開されてしまいます。「作業中は今のサイトを触らない」「どうしても直すときは担当者が新しいページを一時的に外してから公開する」など、ルールを先に決めてください。コースの価格変更やブログの公開は、ストア・ブログの管理画面から行えばページの公開とは別に反映できるか、エンジニアが確認します。

移行で気を付けること

  • 受信先と自動メールを引き継ぐ：今のフォームが誰に通知し、どんな自動メールを送っているかを棚卸しで書き出し、新しいフォームにも同じ設定をします。
  • パンフレットの仕組みは作り直さず使う：今の「送信後すぐダウンロード」がどう作られているか（フォームの設定か、コードか）を確認し、同じ方法をお役立ち資料にも使うと手間が少なくなります。
  • 受け取り方式の比較（お役立ち資料）：A. すぐダウンロード（見本どおり・待ちなし。実在しないメールでも受け取れる）／B. メールで送る（実在するアドレスだけ集まる）／C. 両方。メールアドレスを集める目的なら C。
  • 迷惑な送信対策：reCAPTCHA を有効にする。
  • お知らせメールの同意（特定電子メール法）：同意した人にだけ送る。同意の記録を残し、メールに送信者名と配信停止の方法を入れる。チェックを最初からオンにするなら、はっきり見えるように。
  • 送信元メール：@thesocialjapan.com から送るなら、ドメインの送信設定（SPF・DKIM）をする。
  • PDF の置き場：Wix のメディアの PDF は、URL を知っていれば誰でも開ける。限定したい資料は会員専用ページかメールのリンクにする。

URL・SEO・計測

  • URL 対応表を作り、301 転送を設定する：今の URL が変わるページ（コースの商品ページ、About、ホワイトペーパー、無料体験など）は、Wix の「URL リダイレクト」で新しい URL へ転送します。検索順位と、外部・広告・SNS からのリンクを失わないためです。
  • 変えない URL：ブログ記事の URL はそのまま。
  • 新しい URL：/courses、/courses/コース名、/how-to-learn、/portfolio、/blog、/beginners、/contact、/faq、/resources、/evidence、/privacy、/tokushoho、/terms
  • 直すもの：プロジェクトマネジメントの URL が /products/test のままになっている件、フッターに残っている Wix の初期 SNS リンク。
  • ページ内のリンク先：FAQ の #q-refund、はじめての方への #line・#price・#flow、無料相談の #pamphlet・#form は同じ名前で作る。
  • ページごとの設定：タイトル、説明文、OGP 画像。
  • 計測：GA4 の設定を引き継ぎ、次の操作をイベントにする。無料相談の予約完了、パンフレット・資料のダウンロード、LINE ボタンのクリック、購入ボタンのクリック、コース診断の完了。移行の前後で数字を比べられるよう、切り替え日を記録しておく。

法務・個人情報

  1. 今の法務ページを差し替える：今のプライバシーポリシー・利用規約・特商法の表記（あれば）を、確定版の文面に入れ替えます。古いページの URL が変わるなら転送します。
  2. Wix を使うことの追記：フォーム・予約・会員の情報は Wix（海外の事業者）に保存されます。プライバシーポリシーの「業務の委託」に Wix を含め、外国で扱う場合に必要な記載（外的環境の把握など）を足します。
  3. Cookie の送信先：Google アナリティクスに加え、Wix 自体やブッキング・会員機能・埋め込み動画なども情報を送ります。実際に使う機能を一覧にして P7 に追記し、Cookie 同意バナーを出すか決めます。
  4. 購入画面の表示：カートの最終確認画面で、価格（税込）・支払い時期・提供時期・返金の条件が確認できるようにします（特商法）。
  5. 月額プランを始めるとき：特商法の表記に「契約期間・自動更新・解約方法」を足し、申し込みの最終確認画面にも出します。
  6. 公開前に専門家の確認を受けます。

公開前のチェック

  • 4つの画面幅で、横にはみ出していない・文字が切れていない
  • 全ページのリンクが開く（ヘッダー・フッター・ページ内リンク）

  • フォーム：送信 → 連絡先に入る → 自動メールが届く → 担当者に通知が来る。パンフレット・資料がダウンロードできる
  • 無料相談の予約：枠の表示 → 予約 → 確認メール → Zoom の URL
  • 仮の値（オレンジの「要確認」「仮の数字」）が残っていない
  • 法務3ページの制定日・追記・専門家確認
  • GA4 のイベントが記録される
  • 公開前にサイト履歴で、戻せる版を確認した
