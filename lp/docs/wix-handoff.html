HANDOFF FOR WIX

The Academy サイトを Wix で作るときの実装ガイド

エンジニア・Webデザイナー向けの引き継ぎ資料です。いまのデザイン見本（HTML）を Wix に移すときの作り方、データとフォームの扱い、法務・個人情報の注意点、決まっていない確認項目をまとめています。

結論と前提 渡すもの ページごとの作り方 データ（CMS）の設計 フォーム 動きのある部品 法務・個人情報 URL・SEO・計測 デザインの再現 運用 確認項目の一覧

結論と前提

1. いまの HTML は「完成見本（仕様書）」です。Wix にそのまま貼り付けるものではありません。
Wix の「HTML を埋め込む」機能は枠（iframe）の中に表示するだけなので、検索エンジンに読まれにくく、高さの自動調整やスマホ表示も崩れやすくなります。見た目と動きは Wix のエディタで作り直してください。

2. エディタは Wix Studio をおすすめします。
PC・タブレット・スマホでレイアウトを細かく分けられ、CSS とコード（Velo）も使えます。今のデザインの再現度がいちばん高くなります。

3. 増えていくもの（コース・記事・資料・FAQ）は CMS で管理します。
コース詳細13ページを1枚ずつ作るのではなく、1つのテンプレートと CMS のデータからページを作ります（動的ページ）。追加・修正がデータの入力だけで済みます。

4. 個人情報は Wix（海外の事業者）に保存されます。
プライバシーポリシーへの追記が必要です（法務・個人情報）。

データ（CMS）の設計

見本の元データ（lp/scripts/ の中のリスト）をそのまま CMS の項目にできます。最低限、次の4つのコレクションを作ります。

コース

スラッグ（URL用）、コース名、カテゴリ（IT・デジタル／英語・TOEIC／ビジネス／マーケティング／クリエイティブ）、一言説明、レベル（ベーシック／プロ／プレミア）、学習の目安（例：8週間）、週の時間、価格（税込）、カード画像、成果物の名前・画像、学習の流れ（ステップの一覧）、こんな方に（3つ）、できること（3つ）、関連コース（参照）、表示順、公開／非公開

資料（お役立ち資料）

資料名、カテゴリ、説明、形式とページ数（例：PDF・4ページ）、表紙の色または表紙画像、PDF ファイル、新着フラグ、公開日、公開／非公開

FAQ

カテゴリ（お申し込み／お支払い／返金／視聴関連／機能・操作／サービス）、質問、回答（リンク可のリッチテキスト）、検索用キーワード、アンカー ID（例：q-refund。ほかのページから直接開くため固定にする）、表示順

記事

Wix ブログの標準項目に加えて、読了時間、著者、カテゴリをそろえる。

入力ルールを決めておく：価格は「税込・数字のみ」、学習の目安は「◯週間」で統一、のように書き方をそろえると、比較表や診断の計算が壊れません。

お役立ち資料の受け取り方：決めるときの比較

方式しくみ長所短所
A. 送信後すぐダウンロード送信後にコードで PDF の URL を開く。2回目以降はブラウザの記録で入力を省く待ち時間なし。見本どおり実在しないメールでも受け取れる。PDF の URL を知っていれば誰でも開ける
B. メールで送る送信をきっかけに自動メールで PDF のリンクを送る（Wix のオートメーション）実在するメールアドレスだけが集まるメールを開く手間がある。迷惑メールに入ることがある
C. A と B を両方その場でダウンロードし、同じリンクをメールでも送るすぐ手に入り、メールの確認にもなる設定がいちばん多い

おすすめは C です。資料の目的がメールアドレス集めなら、送ったメールが届くことを確かめられる方式が必要です。

どの方式でも必要なこと

  • 迷惑な送信を防ぐ：Wix フォームの reCAPTCHA を有効にする。
  • お知らせメールの同意：特定電子メール法により、広告・お知らせメールは同意した人にだけ送れます。同意の記録（いつ・どのフォームで）を残し、メールには送信者名と配信停止の方法を必ず入れます。チェックボックスを最初からオンにする場合は、文字を小さくせず、はっきり見えるようにします。迷うならオフが安全です。
  • 送信元メールの設定：自動メールを @thesocialjapan.com から送るなら、ドメインの送信設定（SPF・DKIM）をして迷惑メール扱いを防ぐ。
  • PDF の置き場：Wix のメディアに置いた PDF は、URL を知っていれば誰でも開けます。限定したい資料だけは、会員専用ページに置くか、メールで期限付きのリンクを送る方式にします。
  • 入力の誤り：未入力・メール形式の誤りは、送信前にその場で知らせる（見本と同じ文言）。

法務・個人情報で気を付けること

法務3ページの文面は、自社サイトで管理する前提で作りました。Wix を使うことによる追記が必要なので、公開前に専門家の確認を受けてください。

  1. Wix に個人情報を預けることを書く：フォーム・予約・会員の情報は Wix（海外の事業者）のサーバーに保存されます。プライバシーポリシーの「業務の委託」に Wix を含め、外国で個人データを扱う場合に必要な記載（その国の制度を把握していること＝外的環境の把握、など）を足します。
  2. Cookie の送信先を足す：今は「Google アナリティクスのみ」と書いています。Wix 自体も Cookie を使い、ブッキング・会員機能・埋め込んだ動画なども情報を送ります。実際に入れた機能を一覧にして、P7 に追記します。Wix の Cookie 同意バナーを使うかどうかも決めます。
  3. お知らせメールの同意：上のフォームのとおり（特定電子メール法）。
  4. 月額プランを始めるとき：Wix の料金プラン機能を使う場合も、特商法の表記に「契約期間・自動更新・解約方法」を足し、申し込みの最終確認画面に同じ内容を出す必要があります。
  5. 購入画面の表示：コースの購入画面（カート）でも、価格（税込）・支払い時期・提供時期・返金の条件が確認できるようにする（特商法の最終確認画面のルール）。

URL・SEO・計測

  • URL をそろえる：見本は確認しやすいように courses.html のような名前ですが、Wix では /courses、/courses/sns-marketing、/faq、/resources、/privacy、/tokushoho、/terms のように拡張子なしにします（サイト構成図の URL どおり）。
  • 今の URL からの転送：今の Wix サイトで URL が変わるページは、Wix の「URL リダイレクト」で 301 転送を設定します。外部から来た人・検索順位を失わないためです。
  • ページ内リンク：FAQ の #q-refund、はじめての方への #line・#price、無料相談の #pamphlet・#form は、ほかのページから直接飛んでくるので、アンカーを同じ名前で作ります。
  • ページごとの設定：タイトル、説明文、SNS で共有したときの画像（OGP）。見本には OGP 画像がないので、新しく用意します。
  • 計測：Google アナリティクス（GA4）は Wix のマーケティング連携から入れます。次の操作をイベントとして記録すると、どこから申し込みにつながったか分かります。
    • 無料相談の予約完了、パンフレット・資料のダウンロード、LINE 友だち追加ボタンのクリック、コース詳細の購入ボタンのクリック、コース診断の完了
  • 受講システムが別ドメインの場合：カートやログインが Wix の外なら、GA4 のクロスドメイン設定をして、サイトから購入までを1人の流れとして追えるようにします。

運用

  • 更新の担当と手順を決める：コースの追加、記事の公開、資料の差し替え、FAQ の追加を、誰が CMS に入力するか。
  • 資料の差し替え：資料は随時入れ替わる前提です。CMS で非公開にすれば一覧から消え、新着フラグで先頭の大きな枠に出ます。特定の資料を固定でおすすめする書き方はしない方針です。
  • 告知バー：内容を変えるたびに ID を変える（閉じた人にも新しい告知を出すため）。
  • 公開前のチェック：4つの画面幅で横にはみ出していないか、全リンクが開くか、フォームの送信と自動メールが届くか。
  • 戻せるようにする：大きな変更の前に、Wix のサイト履歴で戻せる版を確認しておく。
